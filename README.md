# RGBRush

A small interactive web application built using **HTML, CSS, and JavaScript**. This project demonstrates basic DOM manipulation, event handling, and responsive UI design with interactive elements.

Built with HTML, CSS, and JavaScript; includes dynamic interactions, hover effects, and real-time updates on user input. Focused on practicing JavaScript fundamentals and enhancing user experience through responsive design.

---

## Tech Stack

HTML, CSS, JavaScript

---

## Features

- Interactive user interface  
- DOM manipulation for dynamic content  
- Event handling for buttons and inputs  
- Responsive design for desktop and mobile  
- Real-time feedback for user actions
